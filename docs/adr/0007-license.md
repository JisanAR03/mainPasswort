# ADR-007 License

Status: Proposed
Date: 2026-10-15

## Context
pykeepass is GPL-3, and the project may be open-sourced.

## Decision
The design pack proposes GPL-3.0. The owner has not decided yet (open question Q6): the
license stays open for now, and no LICENSE file is added. This ADR must be settled before
any public release.

## Consequences
If GPL-3.0 is chosen, anyone who distributes a modified version must share its source, and
pykeepass stays a viable dependency. MIT would require dropping pykeepass for the custom
format. Until a license is chosen, all rights are reserved and the repository is effectively
source-available.
