# ADR-005 Build the extension before sync

Status: Accepted
Date: 2026-10-15

## Context
The brief orders sync before the extension.

## Decision
M4 extension, then M5 sync.

## Consequences
Daily browser use arrives sooner, on a local-only vault where data loss is unlikely.
Multi-device use waits until M5, and KeePassXC with manual copies covers the gap.
