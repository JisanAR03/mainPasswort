# ADR-004 Sync: whole encrypted file on Drive with version checks

Status: Accepted
Date: 2026-10-15

## Context
Drive must never see plaintext, and edits must never be silently overwritten.

## Decision
`drive.file` scope; one Google account per profile; the refresh token stored inside the
vault; sync runs only while unlocked; the pure `decide()` function governs every action.

## Consequences
Locked profiles do not sync. Drive v3 has no atomic conditional upload, so a post-upload
revision check closes the race.
